# Trenches 2 Riches

**Short Name:** T2R

Trenches 2 Riches is a Windows-first persistent open-world project
built with Unreal Engine 5.

The initial world targets a realistic recreation of Ashtabula, Ohio,
with systems planned for exploration, vehicles, properties, businesses,
jobs, missions, progression, economy, multiplayer, social interaction,
crime/police gameplay, and downstream digital ownership.
